# Auth images

Place your login background image here:

- **building-bg.jpg** – Fullscreen background for the login page (office tower / city building recommended).
  - Used as: `url('assets/images/auth/building-bg.jpg')` with `center/cover no-repeat`.
  - Recommended size: 1920×1080 or larger.
  - A frosted glass overlay is applied on top; use a high-quality building photo.

If `building-bg.jpg` is missing, the login page will show a solid dark background (`#0a1929`).
